# Admin: Labour Rates

## Purpose
The **Labour Rates** page allows administrators to create and manage labour rate codes used throughout Works Orders and costing.  
A labour rate defines the hourly cost applied when labour is booked against a job.

Accurate labour rates ensure correct costing, pricing, and profitability analysis.

---

## What You Can Do Here

### Add New Labour Rates
Click **Add** to create a new labour rate.  
Enter:

- Rate code (e.g., STD, SK1, ENG)  
- Description  
- Hourly rate value  
- Status (active or inactive)

### Edit Existing Labour Rates
Select a labour rate and click **Edit** to update:

- Code  
- Description  
- Hourly rate  
- Status  

### Delete Labour Rates
Select a labour rate and click **Delete** to remove it.  
A labour rate can only be deleted if it is **not** referenced by any Works Orders.

---

## Key Fields

### Rate Code
A short identifier for the labour rate, such as:

- **STD** – Standard  
- **SK1** – Skilled Level 1  
- **ENG** – Engineer  

### Description
A human‑readable description of the rate.

### Hourly Rate
The cost per hour applied when labour is booked.

### Status
Indicates whether the rate is active.  
Inactive rates cannot be selected in Works Orders.

---

## Workflow Context
Labour rates are used in:

- Works Order labour booking  
- Costing calculations  
- Profitability reporting  
- Quoting (if applicable)

Changing labour rates affects future costing but does **not** alter historical Works Orders.

---

## Notes & Tips

- Use clear, consistent rate codes for easy selection.  
- Deactivate old rates instead of deleting them if they may be needed later.  
- Ensure hourly rates are correct before releasing them to production.  
- Review rate usage before deleting a rate.

---

## Crib — Labour Rates
- Click Add to create a new labour rate. Enter a rate code, description, hourly rate, and set the status to active or inactive.
- Select a labour rate and click Edit to update its code, description, hourly rate, or status.
- Select a labour rate and click Delete to remove it. A labour rate can only be deleted if it is not referenced by any Works Orders.
